# Music: sources and credits

Every track in this folder (and in `music/`) plays while reading; the app
finds them by itself (`lib/services/music.dart`). Name a file
`Artist - Title.mp3` and the player shows "Title · Artist"; a note in
brackets at the end, such as "(freetouse.com)", is left out.

| File | Track | Artist | Source |
|---|---|---|---|
| `Lukrembo - Jay (freetouse.com).mp3` | Jay | Lukrembo | [freetouse.com](https://freetouse.com/music) |
| `massobeats - daydream (freetouse.com).mp3` | Daydream | massobeats | [freetouse.com](https://freetouse.com/music) |

Free To Use music asks for credit wherever it's used, in this form:
"Music track: Jay by Lukrembo. Source: https://freetouse.com/music". The
app shows these credits on its licences page (Settings → About → Licences).
Check freetouse.com's current licence allows use inside an app before a
public release.
